# ⌚ SPAKAchrono — Watch Store Website

**SPAKAchrono** is a front-end e-commerce website designed for a modern watch brand. The website combines elegant visual design with a simple and user-friendly shopping experience, allowing users to explore different types of watches, learn about the brand, browse related content, and manage items through a shopping cart.

> **"Your Legacy in Time"**

## 📌 Project Overview

SPAKAchrono was developed as a web-based watch store to provide customers with an engaging online platform for exploring and purchasing watches.

The website focuses on combining **timeless watch aesthetics with modern web design**, featuring product showcases, promotional sections, informational pages, and interactive elements.

The homepage includes an image slider, brand introduction, product sections, navigation, and interactive elements.

## ✨ Features

* 🏠 **Home Page**

  * Brand introduction
  * Promotional content
  * Automatic image slider
  * Featured watch products

* ⌚ **Watch Collection**

  * Browse different watch categories
  * Individual product pages
  * Product information and pricing

* 🛒 **Shopping Cart**

  * View selected products
  * Manage items in the cart
  * Cart page for reviewing purchases

* 📝 **Blog**

  * Watch-related articles and content
  * Informational sections for visitors

* 🔎 **Research**

  * Research and references related to the website design and development

* 👥 **About Us**

  * Team member information
  * Project/team presentation

* 📩 **Contact Us**

  * Contact page for user enquiries

* 🖼️ **Responsive Visual Design**

  * Product images
  * Promotional banners
  * Hover effects
  * Image popups and interactive components

The navigation connects the main areas of the website, including Home, Shop, Blog, Research, Contact Us, Cart, and About Us.

## 🚀 How to Run the Project

### Option 1 — Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Open `homepage.html` in a web browser.

### Option 2 — Using VS Code Live Server

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click `homepage.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.

## 💻 Installation

Clone the repository using:

```bash
git clone https://github.com/kritikap0730/Spaka-chrono.git
```

Navigate into the project:

```bash
cd Spaka-chrono
```

Then open `homepage.html` or launch it using Live Server.

## 🎨 Design

The website uses a watch-focused visual theme with promotional imagery, product cards, hover effects, banners, and a navigation system.

The homepage includes an automatic image slider that changes promotional images at regular intervals.

The project also uses a dedicated CSS stylesheet and separate folders for HTML pages, JavaScript, and image assets.

## 🎯 Project Objectives

The main objectives of SPAKAchrono are to:

* Create an attractive online watch-store interface.
* Provide users with an easy way to explore watches.
* Organize products into different watch categories.
* Demonstrate front-end web development skills.
* Implement interactive elements using JavaScript.
* Practice website navigation and multi-page design.
* Create a visually appealing and user-friendly shopping experience.
